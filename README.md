## Code for the paper 'Why we dive deep: A momentum-based account of depth-first persistence in hierarchically organized goals'

Paper link: https://osf.io/preprints/psyarxiv/y8ztu_v1

Organization of the repository is as follows:

    1. analysis/:  contains the code for the analysis pipeline for the manuscript.
        1.1. Plots used in the paper are generated in the 'analysis/plot_*' scripts
        1.2. Models used for the paper are described in 'analysis/src/models/' 
        1.3. Fitting procedure is described in 'analysis/fit_behavior.py'
        
    2. data/: contains the data for the experiments
